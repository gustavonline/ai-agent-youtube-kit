# ACS repository-local skills

ACS owns the repository-local skills in this shelf. Their standard direct path
is `.agents/skills/<name>/SKILL.md`.

- Primary production route: [`agentic-content-system/SKILL.md`](agentic-content-system/SKILL.md)
- Clone setup route: [`setup-content-system/SKILL.md`](setup-content-system/SKILL.md)
- Read-only audit route: [`audit-content-system/SKILL.md`](audit-content-system/SKILL.md)
- FreeCut video Studio route: [`freecut-studio/SKILL.md`](freecut-studio/SKILL.md)

Add a local skill only for an ACS/System-specific repeatable method or eval.
Cross-project or Global skills belong outside ACS and are installed by the
plugin or harness that owns them. AIOS, templates, and releases must not
overwrite these repository-local skills.
