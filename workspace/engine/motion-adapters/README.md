# Legacy Motion-Adapter Recovery Inputs

HyperFrames assets remain in `workspace/engine/motion-adapters/video-projects/`
only for explicit migration/recovery and backward-compatible inspection. They
are not an ordinary overlay choice, editor route, or prerequisite. FreeCut is
the one normal supervised video Studio route. A new concrete motion need
may use Remotion or another bounded code-based ACS technique without reviving
these legacy projects as active choices. The declarative ACS contracts, FFmpeg
outputs, approval, and proof stay local to the production workspace.
