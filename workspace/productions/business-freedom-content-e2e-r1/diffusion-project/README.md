# Business Freedom motion source

This ACS-owned Diffusion project renders the bounded acceptance production. It is 42 seconds at 1920×1080 and 30 fps. The project contains only Diffusion-native shapes, text, groups, sequences, strokes, and keyframes using Inter/system fonts.

It loads no media, HTML, HTML paint, WebGPU, shader, cloud-AI, credit, remote-font, or network dependency. The external Diffusion r5 Electron/DAPI checkout provides compile, capture, check, export, and the final hidden browser companion; it is not copied or modified here.

The visual source is the accepted immutable `../design-input/DESIGN.md` plus its three selected keyframe references. Runtime does not depend on those files.
