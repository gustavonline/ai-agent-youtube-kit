# ACS workspace

- `channel/` holds clone profile, style, accepted design direction, and
  selected reusable assets.
- `content-formats/` and `content-pipeline/` hold planning context.
- `productions/` holds one file-based production per real outcome.
- `references/` and `learning/` hold durable, human-readable learning.
- `engine/` holds the small validators, tests, templates, and optional local
  transcript/reference helpers.

There is no run database, recovery ledger, media engine, or publisher. A
production's content graph and optional supervised handoff are its local proof.
