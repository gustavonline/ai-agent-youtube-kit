# Content Format Library

`workspace/content-formats/formats.json` is the machine-readable library. It keeps the
nine verified capture formats and the practical groups used by planning:

1. physical guest podcast
2. solo/direct-to-camera
3. screen/slides/Miro
4. physical whiteboard
5. iPad/tablet
6. outdoor + another mode
7. online guest podcast
8. client/case interview
9. vlog

The practical groups are teach/explain, prove/demonstrate, converse/learn, and
humanize/relate. A project chooses one capture format and one practical group;
the choice should follow the buyer question and proof available, not the
platform of the day.

The default editorial shape is promise + proof + plan, usually in three points,
with a contextual CTA and an outro to the next useful video. A core video can
be harvested into selected short and text derivatives. The default planning
target is three core videos per week for 26 weeks (78 core videos) plus 22
useful shorts (100 assets). Vlogs are a minority format, usually about 5–20%.

Research provenance and the distinction between attributed creator claims,
transcript observations, and ACS design decisions are recorded in
[`docs/RESEARCH_PROVENANCE.md`](RESEARCH_PROVENANCE.md). The machine-readable
library links to the same resource through its `research_provenance` field.
