# Branding

Keep each branded clone's durable direction in `workspace/channel/` and its
learning in `workspace/learning/`. Do not mix client-specific direction into a
generic base clone.

Read the profile, style guide, accepted design snapshot, project memory, and
selected assets before production. Replace `workspace/channel/DESIGN.md` only
with direction accepted by its design owner.

ADS is optional. When an accepted ADS/design-owner handoff is needed by one
production, copy the immutable `DESIGN.md` plus selected assets into that
production and record revision, hashes, provenance, and review reference in
the graph. Do not copy editable design work or create a runtime dependency.

For ordinary video, apply direction in Diffusion. For a specialist code-animated
video or bounded overlay, follow the upstream HyperFrames route. Do not retain
branded HyperFrames project copies in ACS.
