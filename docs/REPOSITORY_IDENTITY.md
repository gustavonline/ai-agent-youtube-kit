# Repository identity

The product is **Agentic Content System (ACS)**. The canonical repository is
`onlinesourdough/Agentic-Content-System` and the issue tracker is
https://github.com/onlinesourdough/Agentic-Content-System/issues.

runtime contracts. ACS is a file/skill/contract system; it has no installed
application command or Python package identity.
