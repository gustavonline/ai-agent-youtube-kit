# Motion Philosophy

Use this before making a new HyperFrames scene.

## Principles

1. Every scene needs one job.
2. The viewer should know where to look before the animation starts.
3. Text must be readable at phone size.
4. Animations should explain, reveal, or emphasize. They are not decoration.
5. The best frame in the scene should be designed before the first tween is written.
6. Verify rendered frames, not just code and lint output.

## Preflight Checklist

- Does this project have a `DESIGN.md`?
- Is the target format clear: 9:16 short, 16:9 long-form, or overlay with alpha?
- Are captions above UI-safe zones and not covering the face?
- Do transitions land on beat or word boundaries?
- Did `npm run check` pass?
- Were hero frames visually inspected?
